> 本项目出自 **Space Creator EX（SCEX）服务器**的实际玩法需求，是一个由服务器需求驱动、AI 辅助实现并由维护者审阅的 **Vibe Coding 成果**。

## 这是什么

这是 Minecraft 1.21.1 + NeoForge 下的 ViScriptShop × Applied Energistics 2 兼容附属。它保留 ViScriptShop 原生商店功能，让玩家通过自己放置的 ME 商店连接器，直接使用个人 AE2 仓库交易。它不是 ViScriptShop 或 AE2 的官方项目。

## 有什么用

- 从已绑定的 ME 网络读取并出售物品；
- 把购买获得的物品直接写入 ME；
- 原生商店数量合并背包与 ME；
- 直接识别 ME 中的 SCEX 货币，并与数字余额组合付款、自动找零；
- 交易先模拟空间，再统一提交物品、货币、经验和库存；失败或异常退出时通过事务日志回滚/恢复；
- 无可用连接器时自动退回 ViScriptShop 原生背包交易。

## 0.3.3

- 未激活、断电、离线或缺频道时，连接器只显示基础材质；
- AE 节点激活且在线后才显示慢速、平滑的彩色信号动画；
- 物品栏和手持连接器使用无彩色信号的基础外观。

## 环境与安装

需要 Minecraft 1.21.1、NeoForge 21.1.248、Java 21、ViScriptShop 1.2.0、AE2 19.2.17。模组必须同时安装在服务端和客户端。只把无后缀的正式 JAR 放进 `mods`，不要安装 `sources` JAR。
